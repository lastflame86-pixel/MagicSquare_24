## Executive Summary

이번 세션에서는 프로젝트용 전문 에이전트 세트를 순차적으로 생성했다. 코드 리뷰, 최적화, UX, 오케스트레이션, PM, 서버/클라이언트 개발, QA 역할을 분리해 `.cursor/agents` 아래에 정의했다. 또한 `backup-agent`를 추가하고, Prompt 백업 시 요약 없이 사용자 Prompt와 AI 답변 전문을 Export하도록 규칙을 강화했다.

## 목표·범위

- 사용자 요청에 맞는 역할별 에이전트 파일 생성
- 백업 에이전트 루틴 정의(보고서/프롬프트 Export/백업)
- Prompt Export를 Full transcript 정책으로 수정

Out of scope:

- 프로덕션 코드(`src/`) 기능 구현
- 테스트(`tests/`) 추가/수정
- Git push
