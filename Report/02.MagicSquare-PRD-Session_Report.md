## 주요 산출 요약

### PRD v0.1 핵심 결정(확정)

- 입력: 4×4, `0` 정확히 2개, 값 `0` 또는 1~16, 0 제외 중복 금지
- 출력 성공: `int[6]` `[r1,c1,n1,r2,c2,n2]` (1-index)
- Solver: small-first → reverse, 모두 실패 시 `ERR-SOL-001` + `SolveStatus.UNSOLVABLE`
- Boundary 입력 실패 시 Domain(Solver 포함) **0호출**
- NFR: Domain coverage ≥95%, Boundary ≥85%, 동일 입력 동일 출력, 입력 배열 불변

### PRD 검토 — 우선 개선 6건

1. DATA-SOL-A1/A2 수치·Attempt PASS/FAIL 속성 확정 (DEC-003)
2. BR-05b(두 번째 빈칸) + AC-DOM-002c
3. Traceability Matrix에 AC ID 열 추가
4. FR-05 Domain/Boundary 분리 또는 중간 DTO 명시
5. DEC-002(오류 DTO vs 예외) 확정
6. DEC-001 — Report/2 검증-only vs 본 PRD Solver Phase 분리
