# PRD 검토 보고 — 누락·모순·모호함

PRD 초안(이전 턴 출력)을 요청하신 7개 기준으로만 검토했습니다. **수정·재작성은 하지 않았습니다.**

---

## 1. 모든 FR에 테스트 가능한 AC가 있는가?

| FR | 판정 | 문제 | 개선안 |
|----|------|------|--------|
| **FR-01** | **대체로 충족** | `AC-BND-ISO-01`이 4개 오류를 한 AC에 묶음 — Red 1건 원칙(§15.3)과 충돌 가능 | AC-BND-ISO-01을 **오류 유형별 4 AC**로 분리하거나, “ISO는 통합 스파이 테스트 1건”임을 §15에 명시 |
| **FR-02** | **부분 누락** | **두 번째 빈칸** 좌표에 대한 AC 없음. `AC-DOM-002b`는 전제 조건 문장이라 Then이 아님 | `AC-DOM-002c`: row-major **두 번째** `0`의 `(row0,col0)` 기대값 검증 추가 |
| **FR-03** | **충족** | `DATA-MISS-01`이 §16.4에 **선언만** 되고 행렬 없음 | `AC-DOM-003`에 “고정 격자 1건”을 Appendix 데이터 표로 연결 |
| **FR-04** | **부분 누락** | `AC-DOM-004-FAIL-ROW`만 있고 **열·주대각·부대각** 실패 AC 없음 | `AC-DOM-004-FAIL-COL/M3/M4` 최소 1건씩 또는 “M2~M4는 M1과 동일 패턴” 단일 AC로 명시 |
| **FR-05** | **충족(데이터 미확정)** | `AC-DOM-005-A1/A2`는 통과 기준이 있으나 **수치 격자 없으면 Red 작성 불가** | DEC-003 해소 전 AC에 “DATA-SOL-A1/A2 확정 시에만 적용” 게이트 명시 |

**요약:** FR 단위 AC **존재**는 하지만, FR-02(두 번째 빈칸)·FR-04(열/대각 실패)·FR-05(픽스처 미확정)는 **실행 가능한 Red 기준까지는 미완**.

## 2. 모든 AC가 Traceability Matrix에 연결되어 있는가?

| AC ID | Matrix 연결 | 문제 |
|-------|-------------|------|
| AC-BND-001~004 | 간접(Concept→TP-E) | Matrix에 **AC ID 열 없음** — Concept 행만 있어 AC↔행 1:1 감사 불가 |
| AC-BND-ISO-01 | 1행( Domain 미호출) | **AC-BND-001~004와 1:1 행 없음** |
| AC-DOM-002b | **없음** | Matrix 누락 |
| AC-DOM-003b, 003c | `AC-DOM-003`에 흡수 | 003c(개별 숫자 검증) **별도 행 없음** |
| AC-DOM-004-FAIL-DUP | **없음** | “중복 금지” 행은 FR-01·Boundary만 연결 |
| AC-DOM-004-FAIL-ROW | “행/열/대각선 합” 1행 | **열/대각 실패 AC 미반영** |
| AC-DOM-005-A1, A2 | 있음 | — |
| AC-SOL-001 | 있음 | — |
| AC-BND-005 | `int[6]`·`1-index` 2행 | **중복 행** — 1 AC가 2 Concept에만 나뉘고 AC ID는 없음 |

**개선안:** Matrix에 **AC ID 열**을 추가하고, §10·§13의 **모든 AC-*를 1행 이상**에 매핑(누락 0건 체크리스트).

## 3. Boundary와 Domain 책임이 섞인 곳은 없는가?

| 위치 | 판정 | 문제 | 개선안 |
|------|------|------|--------|
| **FR-05** | **경계 모호** | Description·Processing·Output에 **Attempt 규칙(Domain)** 과 **`int[6]`·1-index(Boundary)** 가 한 FR에 공존 | FR-05를 **FR-05a Solver(Domain)** / **FR-05b Result Formatting(Boundary)** 로 분리하거나, “Domain 출력은 0-index 중간 DTO”를 명시 |
| **§12.2 Output** | **혼선** | 성공 계약이 Boundary 표에 있으나 **Attempt1/2 순서**는 Domain 규칙 — Formatter가 순서를 바꿀 수 없음을 BR로 고정 | BR-13: “`n1,n2` 순서는 Solver가 확정한 Attempt 결과와 동일” 추가 |
| **FR-04 vs FR-01** | **중복 검증** | FR-01이 범위·중복 검사, FR-04가 완성 격자에서 다시 중복·범위 — **책임은 분리 가능**하나 FR-04가 “시도 격자”에도 V 규칙 재적용 | FR-04 Input을 “FR-01 통과 원본 + Solver가 만든 **완전 복사본**”으로 한정 |
| **§13 ERR-SOL-001** | **양호** | Domain `UNSOLVABLE` + Boundary `ERR-SOL-001` 이중 표기 — 역할은 구분됨 | SolveOrchestrator가 Boundary에 전달하는 **계약 DTO** 필드 1개로 통일 |

**요약:** “호출 금지”는 명확하나, **FR-05·출력 순서·좌표 변환 주체**에서 읽는 사람이 Boundary/Domain을 혼동할 여지가 있음.

## 4. 오류 정책이 미정으로 남아 있지 않은가?

| 항목 | 판정 | 문제 | 개선안 |
|------|------|------|--------|
| 두 조합 실패 | **확정** | `ERR-SOL-001` + `UNSOLVABLE` — §22에서 확정 항목으로 명시됨 | — |
| 입력 검증 실패 | **확정** | ERR-BND-001~004, Domain 0호출 | — |
| **DEC-002** | **미정** | Boundary: **DTO 반환 vs 예외** — §13은 “예외 비전파”만 있고 pytest/호출자 관측 방식 불일치 가능 | DEC-002 결론을 §13에 반영(한 가지만 Canonical) |
| **null/빈 참조** | **누락** | `grid == null`, jagged row 길이 불일치 | `ERR-BND-000` 또는 001에 포함 규칙 추가 |
| **두 번째 빈칸** | **부분 모호** | 실패 정책은 아니나 **탐색 규칙**이 BR 표에 없음 → Solver 오동작 시 어느 ERR인지 불명 | BR-05b “두 번째 `0` = row-major 두 번째” 추가 |
| **DEC-001** | **미정** | Report/2 PASS/FAIL/NA와 본 PRD ERR-* **공존** 시 오류 체계 이중화 | Phase 분리 또는 오류 코드 네임스페이스 접두사(`BND-` vs `VAL-`) |

**요약:** 핵심 실패(입력·UNSOLVABLE)는 확정. **전달 메커니즘(DEC-002)·null·Report/2 공존**은 여전히 미정/이중.

## 5. small-first / reverse 테스트 데이터가 구분되어 있는가?

| 항목 | 판정 | 문제 | 개선안 |
|------|------|------|--------|
| **DATA-SOL-A1 / A2** | **라벨만 구분** | §16.4에 용도는 다르지만 **수치 행렬 없음**, “팀이 수치 확정”, DEC-003 | Appendix에 A1/A2 **속성 표**: Attempt1 결과, Attempt2 결과, 기대 `int[6]` (1-index) |
| **혼동 방지** | **약함** | TP-N-01/02와 DATA ID 연결은 있으나 **동일 격자를 공유하면 안 됨**이 문장으로 없음 | “A1 격자에서 Attempt2는 **반드시 FAIL**” 등 **불변 속성**을 데이터 정의에 포함 |
| **SC-DOM-SOL-001** | **Gherkin만** | Appendix 시나리오는 있으나 **DATA-SOL-A2와 1:1 ID 링크 없음** | Gherkin `Examples` 테이블 ID = DATA-SOL-A2 |

**요약:** **개념적으로는 구분**, **실제로 Red를 쓸 수 있는 수준의 데이터 분리는 미완**(DEC-003).

## 6. 1-index 좌표와 row-major 규칙이 누락되지 않았는가?

| 규칙 | 포함 여부 | 문제 | 개선안 |
|------|-----------|------|--------|
| row-major **첫** 빈칸 | BR-05, AC-DOM-002 | — | — |
| row-major **둘째** 빈칸 | FR-05 문장만 | **BR·Matrix·AC 없음** | BR-05b + AC-DOM-002c |
| 1-index 출력 | BR-11, AC-BND-005 | **0-index→1-index 변환 공식** `(r0+1, c0+1)` 미기재 | §12.2에 변환 규칙 1줄 |
| `r1,c1`이 **어느 빈칸**인지 | Attempt 문장에 의존 | “첫 빈칸=첫 `0`”와 “Attempt1에서 small이 들어가는 칸” **동일 좌표**임을 BR로 고정 | BR-14: `r1,c1` = BR-05 첫 빈칸의 1-index |
| reverse 시 좌표 의미 | AC-DOM-005-A2 | **숫자만 바뀌는지 좌표도 바뀌는지** — 같은 두 칸에 swap인지 명시 | “좌표 쌍은 동일, `n1,n2` 순서만 Attempt2 규칙” 문장 추가 |

**요약:** 첫 빈칸·1-index는 있음. **둘째 빈칸 BR·좌표-숫자 매핑 불변**이 약함.
